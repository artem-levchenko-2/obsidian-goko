# Pictures

The pictures the README points at. Obsidian's directory renders the README
as the plugin's page and rewrites these relative paths, so they belong in the
repository rather than on an image host.

Shoot them in dark mode on a wall with real clippings — a page of placeholder
rectangles sells nothing. PNG; the desktop two at about 1600px wide, the phone
at about 780, which is three times the width it is shown at. No scaling up.

| file | what is in it |
| --- | --- |
| `banner.svg` | The header: the word in block letters with a double-line shadow, in Obsidian's accent purples on its dark background. Drawn, not shot, so it is edited as text; the comment inside says how it is built. |
| `wall.png` | The whole wall with the rail open: many cards, tall beside wide, grids and their folders down the left. The one picture someone decides on. |
| `card.png` | One card picked, the details panel open beside it — palette, source, categories, the summary and a note. Pick a clipping whose metadata is full. |
| `phone.png` | An iPhone screenshot of the wall. It is rendered at 260px wide, floated right, so it needs to read small. Crop the status bar if it carries anything personal. |

Before committing, look at each one at the size GitHub renders it — about 850px
wide — and ask whether it still says what it is for.
